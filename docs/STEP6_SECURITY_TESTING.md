# Step 6 — Security & QA
Production gates:
- HTTPS only
- server-authoritative credits
- JWT/session expiration and refresh
- rate limits and concurrent-job limits
- idempotency on purchases and AI jobs
- Play purchase verification on backend
- secret management
- structured audit logs without payment secrets
- account deletion and data deletion
- privacy policy and Data Safety declaration
- unit, integration and UI tests
- crash/ANR monitoring
- pre-launch report review
