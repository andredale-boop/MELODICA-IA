# Step 7 — Google Play release
Release checklist:
1. Configure application ID and signing key.
2. Build a signed release AAB with target API 36+.
3. Configure subscriptions and one-time credit products in Play Console.
4. Implement server-side purchase verification and entitlement reconciliation.
5. Configure RTDN/Pub/Sub for subscription lifecycle events.
6. Publish privacy policy and complete Data Safety.
7. Provide account deletion path if accounts are created.
8. Run internal testing, then closed testing as required by the developer account.
9. Fix pre-launch issues and verify billing on test tracks.
10. Request production access and publish.
