# Play Store assets checklist

- [ ] Nome app definitivo e coerente con `versionName`.
- [ ] Icona 512×512 PNG conforme alle linee guida Play.
- [ ] Feature graphic 1024×500 PNG/JPG.
- [ ] Almeno 2 screenshot telefono per la scheda Play.
- [ ] Descrizione breve entro il limite Play.
- [ ] Descrizione completa con indicazione chiara delle funzioni IA.
- [ ] URL privacy policy pubblico.
- [ ] URL pubblico cancellazione account.
- [ ] Email sviluppatore e contatti assistenza.
- [ ] Classificazione contenuti completata.
- [ ] Data safety compilata sulla base della release effettiva.
- [ ] App access fornito ai revisori se alcune funzioni richiedono login.
- [ ] Prodotti `credits_500`, `credits_1500`, `credits_5000` creati e testati.
